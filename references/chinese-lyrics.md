# 中文歌词写作

把中文歌词写成可唱的现代口语，而不是书面标语。先确定说话的人、此刻所在的场景和想要完成的情绪移动；再让每个段落只推进一个明确动作或发现。

## 自然表达与行长

- 优先使用当代、具体、可直接说出口的句子。避免为“文艺”而堆砌抽象名词，也避免生硬的倒装和为了凑字的虚词。
- 保持行长可呼吸：主歌通常每行约 6–12 个汉字；副歌可更短、更有留白。若一句必须更长，用停顿、分句或下一行分担信息，不要把多个画面塞进一口气。
- 把自然的口语停顿放在重拍附近。读一遍时若需要急促换气、重音找不到位置，缩短它或换成更日常的说法。
- 人称、时态感和叙述距离要稳定。第一人称的歌让“我”看见、听见、触碰到东西，而不只宣布感受。

## 主歌：场景带来推进

主歌不是把主题重复几次；它应在镜头、动作或认知上向前走。可按“触发画面 → 当下反应 → 新的决定/未说出口的念头”推进。每段引入至少一个可感知的意象（光线、声音、温度、物件、动作），让情绪从画面里长出来。

**弱：**

```text
我很难过你要离开
毕业以后我们会想念
时间过得真的很快
希望我们都越来越好
```

问题：概念化、信息没有推进，像祝福卡片。

**强：**

```text
礼堂的灯一盏盏熄在身后
你把没喝完的汽水塞给我
校门口那辆末班车关上门
我把“明天见”咽成一句保重
```

改进：从毕业夜的连续动作进入告别，具体意象承载了克制的难过。

## 副歌、押韵与 hook

- 副歌只承载一个容易复述的核心句（hook）。它可以重复，但每次重复应因前后的画面或旋律落点而更有重量；不要用“加油”“一定成功”“永远不怕”替代内容。
- 用短而清晰的句子安放 hook；把关键词放在句尾或较强拍位置。用一个新鲜的具体动作、地点或转折，使它不只是口号。
- 押韵服务于流畅和记忆，不必逐行死押。可在两到四行的句尾做松散韵脚、近韵或元音呼应；当强行押韵破坏口语、语义或呼吸时，先保留自然表达。
- 副歌应回应主歌的推进：主歌写“发生了什么”，副歌写“这件事让我怎样选择、记住或离开”。

**弱：**

```text
向前走 向前走
我们一定会成功
不害怕 不害怕
明天会更好
```

问题：副歌是泛化口号，重复没有新信息，hook 不属于这首歌。

**强：**

```text
向前走，把熄掉的街灯留在背后
不是不怕，是我终于敢松手
向前走，鞋底还带着昨夜的雨
天亮以前，我先替自己开门
```

改进：保留“向前走”的可记忆 hook，却以街灯、雨和开门让它属于具体处境。

## 常见失败与修复

| 症状 | 修复 |
| --- | --- |
| 像口号的副歌 | 保留一个核心短句，删掉泛泛的宣言；加入能回扣主歌的动作或意象。 |
| 主歌原地打转 | 给每一段指定新的镜头、动作或认识，检查最后一句是否把歌推向下一段。 |
| 句子太长、没有呼吸 | 拆成两行，删去解释性修饰，保留一个最有力的动词和名词。 |
| 为押韵而别扭 | 改用近韵或隔行押韵；优先口语、语义与旋律重音。 |
| 抽象词过多 | 将“孤独、成长、希望”等词换成看得见或听得见的意象。 |
| 中英混合变成逐句翻译 | 让中文承担叙事与画面，让英文只承担 hook、口令或节奏性回应；不要重复同一信息。 |

交稿前朗读每一段：口语是否自然、行长是否可唱且有呼吸、意象是否具体、主歌是否推进、副歌是否有自己的 hook；若任一项回答是否定，先改歌词再润色辞藻。
